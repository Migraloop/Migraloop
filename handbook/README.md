# Migraloop handbook

Product documentation for **Operators** (run Deployments, author Pipelines, monitor Sync Health / Delivery Health) and **Developers** (local monorepo setup).

English (`en`) is canonical. Traditional Chinese (`zh-TW`) and Simplified Chinese (`zh-CN`) are required peers with the same chapter paths.

Engineering docs (`CONTEXT.md`, `docs/adr/`, `docs/agents/`) stay outside this tree.
