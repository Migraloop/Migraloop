# Multilingual in-repo handbook, separate from engineering docs and CI guards

Operator and Developer product documentation is an in-repo Markdown handbook with English as canonical and required Traditional Chinese (zh-TW) and Simplified Chinese (zh-CN) peers that stay structurally isomorphic. Navigation is primarily functional (Deployment, Pipeline, CLI reference, and related chapters) with a thin progressive Start here path; v1 does not deploy a separate docs site. Human handbook content, Matt Pocock–style agent contracts under `docs/agents`, and CI machine configuration for update guards are three separate trees so obligations and readers do not mix. Engineering artifacts (`CONTEXT.md`, `docs/adr/`) stay outside the three-locale product-doc obligation. Operator- or Developer-visible functional changes must update matching handbook pages in all three locales in the same change; high-signal surfaces are hard-gated in CI, and remaining cases rely on agent/review standards (see Spec #47).
